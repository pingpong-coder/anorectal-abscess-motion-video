# Voiceover assets

Store narration planning text files in this `voiceover/` folder.
For Remotion playback, place recorded `.mp3` files in `public/narration/`.

Suggested naming for optional Remotion audio tracks:

- `public/narration/scene01.mp3`
- `public/narration/scene02.mp3`
- ...
- `public/narration/scene14.mp3`

Each `SceneXX_*.txt` file in this folder includes the Arabic narration source and English narration text for recording.
